Assignment Overview

In this assignment I practiced the core of TypeScript and object-oriented programming: basic types, optional, default and rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises with new Promise and setTimeout, and classes with access modifiers. I solved 8 problems, and all the solutions are in solutions.ts. I also wrote two short blog posts on the concepts I learned.
